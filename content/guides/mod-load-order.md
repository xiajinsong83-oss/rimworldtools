<p>A wrong <strong>MOD load order</strong> breaks RimWorld saves and features. This guide explains how to order MODs and fix problems for the current <strong>1.6 / Odyssey</strong> version.</p>

<h2>Correct Load Order</h2>
<ol>
<li><strong>Core frameworks</strong> (HugsLib, Harmony, etc.) — always first.</li>
<li><strong>Content expansions</strong> (Vanilla Expanded, new items/races).</li>
<li><strong>Gameplay / balance MODs</strong> (Combat Extended, etc.).</li>
<li><strong>UI and quality-of-life MODs</strong> last.</li>
</ol>

<h2>Fix a Broken Save</h2>
<ol>
<li>Disable the <strong>newest MODs</strong> you added first.</li>
<li>If the save loads, re-enable one at a time to find the culprit.</li>
<li>Check load-order dependencies listed on each MOD's Workshop page.</li>
</ol>

<h2>Fix Duplicate / Conflicting MODs</h2>
<p>Two MODs editing the same thing (e.g. the same weapon or animal) conflict. Disable the weaker one, and avoid loading two versions of the same MOD. Back up saves before major changes.</p>

<h2>MOD Load Order FAQ</h2>
<div class="faq-item">
  <h3>Why does my game crash after adding MODs?</h3>
  <p>Usually a load-order dependency or a conflict. Move frameworks first and disable recent additions.</p>
</div>
