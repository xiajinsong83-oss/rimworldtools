RimWorld MOD Load Order — Fix Broken & Duplicate MODs (1.6 & Odyssey)

A wrong MOD load order breaks RimWorld saves and features. This guide explains how to order MODs and fix problems for the current 1.6 / Odyssey version.

Correct Load Order

  1. Core frameworks (HugsLib, Harmony, etc.) — always first.
  2. Content expansions (Vanilla Expanded, new items/races).
  3. Gameplay / balance MODs (Combat Extended, etc.).
  4. UI and quality-of-life MODs last.

Fix a Broken Save

  1. Disable the newest MODs you added first.
  2. If the save loads, re-enable one at a time to find the culprit.
  3. Check load-order dependencies listed on each MOD's Workshop page.

Fix Duplicate / Conflicting MODs

Two MODs editing the same thing (e.g. the same weapon or animal) conflict. Disable the weaker one, and avoid loading two versions of the same MOD. Back up saves before major changes.

MOD Load Order FAQ

Why does my game crash after adding MODs?

Usually a load-order dependency or a conflict. Move frameworks first and disable recent additions.
