How to Use a Seed

When creating a new world, enter the seed code in the World Seed field and set the world size/coverage to match the seed notes. The seed controls terrain generation, so the same seed gives a similar map.

RimWorld Seed FAQ

Do seeds work across versions?

Seeds are mostly version-stable, but map generation details can shift slightly between updates. Test after a major update.

Why is the same seed different?

World coverage and size settings change the generated terrain. Use the settings noted with each seed.
